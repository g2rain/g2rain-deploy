# Shell 与 Compose 约定

- Shell 使用 Bash，并保持 `set -euo pipefail` 兼容。
- 所有路径基于脚本所在仓库根解析，避免依赖调用者当前目录。
- 新参数必须出现在 `--help`、参数解析、运维文档和错误提示中。
- Compose V1/V2 的服务名、依赖、卷、端口、环境变量和健康检查保持语义一致。
- 合并数组和路径始终引用，禁止通过未校验输入构造 `eval`。
- `service_config.d` 是可执行 Shell，不是纯数据；新增来源必须受信任。
- 清理、覆盖、生成密钥、修改 SQL 和远程 Git 操作必须有明确日志与保护条件。
- 示例配置只提供占位用途，不放置可被误用的固定生产凭据或私钥。
