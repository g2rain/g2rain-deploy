# 本地工程基线

中央 G2rain 架构目录当前没有适用于部署编排仓库的正式 Profile，也没有本项目登记项。本仓库采用本地基线 `g2rain-compose-deployment 1.0.0-local`，仅描述当前实现，不代表中央标准已经发布。

## 基线约束

- Shell 脚本使用 Bash 严格模式，生命周期入口为初始化、启动、停止和更新四类命令。
- 同时维护 Docker Compose V1 与 V2 主配置；命令行选项优先于持久化 CLI 偏好。
- 主 Compose 始终先加载，`business.d` 片段随后合并。
- `services.conf` 定义默认源码构建映射，`service_config.d` 按 Compose 服务名追加或覆盖。
- 环境模板不得作为生产配置直接使用；凭据和密钥必须由部署环境安全注入。
- 数据删除、镜像清理、证书生成、源码拉取和构建均属于显式授权操作。

未来中央 Profile 建立后，应固定其版本和基线引用，评审本地差异后再登记采用。
