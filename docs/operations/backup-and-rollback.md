# 备份与回滚

仓库脚本包含更新前备份相关逻辑，但未形成经过验证的完整灾难恢复方案。生产变更前至少保存：

- MySQL 数据库一致性备份及恢复验证记录
- Redis、Nacos、Kafka 所需的持久化数据或可重建说明
- 当前 `.env`、Compose 片段、服务映射和代理配置的安全副本
- 当前镜像 digest、服务版本和源码提交号
- 应用密钥与证书的安全备份及轮换计划

回滚应优先恢复已记录的镜像 digest/提交与配置，再按依赖顺序重建服务。数据库架构或数据发生不可逆迁移时，容器版本回退并不等同于系统回滚。

任何声称“可回滚”的发布，都应在非生产环境实际演练并记录恢复时间和数据一致性结果。
